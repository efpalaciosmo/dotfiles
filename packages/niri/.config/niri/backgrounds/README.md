`adwaita-dark.png` is GNOME's official Adwaita Dark wallpaper, converted from
JPEG XL to PNG and resized/cropped to 2560×1600 for Swaybg compatibility.

Source: [GNOME gnome-backgrounds 49.0](https://github.com/GNOME/gnome-backgrounds/blob/49.0/backgrounds/adwaita-d.jxl).
